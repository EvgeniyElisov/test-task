# Тестовое: инженер по интеграциям и техподдержке

Выбраны **04** (обязательное) и **01**. Задание 06 не делал: при выборе 01 его можно пропустить.

**Почему 01.** Это сверка заказов маркетплейса с номенклатурой 1С — ближе всего к обменам и расхождениям из вакансии.

| Папка | Что внутри |
|-------|------------|
| [`04/04-incidents.md`](04/04-incidents.md) | Разбор четырёх обращений: причина, доказательства, что сделать, как не повторить, ответ сотруднику, порядок приоритета |
| [`01/`](01/README.md) | PHP-скрипт сверки, пример отчёта, лог, исправленный `OrderTotal.php` |

## Как запустить 01

PHP 8.1+, Composer не нужен.

```bash
cd 01
php match.php
php bugs/OrderTotal.php
```

`php match.php` пишет `01/output/report.csv` и `01/output/sync.log` и печатает сводку.  
`php bugs/OrderTotal.php` должен закончиться строкой `Все проверки пройдены`.

Решения по спорным местам (дубли, отмены, остаток, артикул) — в [`01/README.md`](01/README.md).
