## Если бы это шло в прод

1. Очередь обмена со статусом «ошибка», чтобы один отказ 1С не стопорил остальные заказы. Алерт, если очередь стоит дольше N минут.
2. Повторная выгрузка того же заказа не должна создавать второй документ в 1С.
3. Сверку цен и остатков гонять CLI по расписанию, не через HTTP на том же лимите, что сайт. После смены БД — сброс кеша и проверка входа до открытия сайта.
4. На кассах — синхронизация времени; странную дату не принимать молча. К ключам API — доступ только у сервиса обмена.
